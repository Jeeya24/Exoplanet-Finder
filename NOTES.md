## Why this project

I use AI tools all the time, but I didn't really understand how a neural
network learns. I wanted to build one myself and see how it goes from random
guesses to useful predictions.

I chose exoplanets because I've always been curious about space, and finding planets around other stars is a real problem scientists are still working on. It let me learn machine learning on real NASA data instead of a practice
dataset, and learn some astronomy along the way.
